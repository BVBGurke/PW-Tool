# PW-Tool Website

Die Projektwebsite ist ein eigenständiges Vite/React-Projekt und kommuniziert nicht mit dem Passwort-Backend.

```bash
pnpm install
pnpm build
```

Der GitHub-Actions-Workflow baut die Website mit der GitHub-Pages-Basisadresse. Die Pages-Bereitstellung wird erst aktiv, wenn der Repository-Owner GitHub Pages in den Repository-Einstellungen aktiviert.
