# GitHub Pages für PW-Tool

Dieser Ordner enthält die eigenständige, statische Projektwebsite für GitHub Pages. Sie benötigt weder Build-Schritt noch Backend und ist für die Auslieferung aus dem Ordner `docs/` vorbereitet.

Zum Veröffentlichen muss im Repository unter **Settings → Pages** die Quelle **Deploy from a branch**, Branch **`main`** und Ordner **`/docs`** gewählt werden. Danach stellt GitHub die Seite unter der von GitHub Pages ausgewiesenen Repository-URL bereit.

Die Seite dokumentiert bewusst keine Crack-Funktion. Der Abschnitt „Hash-Demo“ beschreibt ausschließlich den lokalen, selbst erzeugten scrypt-Lehr- und Prüfpfad von PW-Tool.
