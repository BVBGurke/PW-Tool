02 / CONSTRUCTION

EIN KLARER PFAD

Was tatsächlich
im Werkzeug
passiert.

OS-CSPRNG

Jedes sichtbare Passwort stammt aus dem Betriebssystem-Zufallsgenerator. Kein Zeitstempel, keine UUID, kein Standard-PRNG.

Zeichen-Policy

Vollständig garantiert Zeichenklassen. Kompatibel bleibt klar auf erlaubte Zeichen begrenzt.

Textual TUI

Schmale Terminals erhalten eine scrollbar kompakte Ansicht. Ergebnisse werden nicht gekürzt.
